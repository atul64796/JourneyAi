# Journey AI – Backend

Journey AI is an AI-powered travel story generation platform.  
This repository contains the **backend service** responsible for authentication, story generation, feedback handling, admin management, and integrations with AI services.

---

## 🚀 Features

- 🔐 JWT-based authentication & authorization
- 👤 User management (ban, activate/deactivate)
- 🛡️ Admin-only protected routes
- ✍️ AI-generated travel stories
- 🗣️ Text-to-speech integration
- 📩 User feedback system with admin responses
- ☁️ Cloudinary image upload support
- 🍪 Secure cookie & token handling

---

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB & Mongoose**
- **JWT Authentication**
- **Google GenAI / OpenAI**
- **Cloudinary**
- **Multer**
- **Render (Deployment)**
